# The Lost Front — Loading Screen

Static loading-screen page for The Lost Front Garry's Mod server.

## Publish with GitHub Pages
1. Upload the **contents of this folder** to the root of your repository (so `index.html` is next to `assets/`).
2. Open repository **Settings → Pages**.
3. Under Build and deployment, select **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
4. Wait for deployment and use the `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/` Pages URL.

Do not use the GitHub repository page URL (`github.com/.../blob/...`) or the raw file URL as the loading-screen URL.

Discord: https://discord.gg/KAehaw6YnP

The progress bar is a visual demo, not real Garry's Mod download progress. Real progress requires integration with a loading-screen framework that exposes download hooks.
